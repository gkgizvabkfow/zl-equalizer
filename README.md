## Overview

ZL Equalizer is a free, open-source parametric EQ with up to 16 bands, dynamic EQ mode with sidechain triggering, oversampling, and a clean phase-linear mode for mastering applications.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **ZL Equalizer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **16 Bands** | Up to 16 parametric bands with peak, shelf, high-pass, and low-pass |
| **Dynamic EQ** | Per-band threshold and ratio for frequency-selective compression |
| **Phase Linear** | Zero-latency minimum-phase and linear-phase processing modes |
| **Oversampling** | 4x and 8x oversampling for alias-free processing at any sample rate |
